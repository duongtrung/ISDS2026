# REPRODUCE.md — run everything from scratch

Exact commands to go from an empty checkout to all results and the compiled paper.
Run all Python with `.venv/bin/python`. Paths are relative to the repo root
(the directory containing this file). See also `RESULTS.md`
(expected numbers). Rule: **no number is hand-edited** — every value in the paper is
generated by a script from `results/*.json`.

## 0. Environment (DGX Spark GB10, aarch64)
```bash
uv venv --python 3.12 .venv
UV_HTTP_TIMEOUT=900 uv pip install --python .venv/bin/python \
    torch==2.12.1 torchvision==0.27.1 --index-url https://download.pytorch.org/whl/cu130
uv pip install --python .venv/bin/python matplotlib tqdm
.venv/bin/python -c "import torch; print(torch.cuda.is_available())"   # -> True
# LaTeX: tectonic (if not on PATH, e.g. in a conda base env: export PATH="$HOME/anaconda3/bin:$PATH")
```

## 1. Datasets + optical flow
Easiest: `bash scripts/download_data.sh` does everything in this section. Manual URLs:
- DAVIS-16: `DAVIS-data.zip` (ETH `cgl.ethz.ch/Downloads/Data/Davis/`) -> `data/DAVIS`
- FBMS-59 test: Freiburg `.../resources/datasets/fbms/FBMS_Testset.zip` -> `data/FBMS`
- SegTrack-v2: OregonState `~lif/SegTrack2/SegTrackv2.zip` -> `data/SegTrackv2`
```bash
# DAVIS ships the old 480p path-list; build the sequence-name split the loader expects:
mkdir -p data/DAVIS/ImageSets/2016
awk '{print $1}' data/DAVIS/ImageSets/480p/train.txt | sed -E 's|.*/480p/([^/]+)/.*|\1|' | awk '!s[$0]++' > data/DAVIS/ImageSets/2016/train.txt
awk '{print $1}' data/DAVIS/ImageSets/480p/val.txt   | sed -E 's|.*/480p/([^/]+)/.*|\1|' | awk '!s[$0]++' > data/DAVIS/ImageSets/2016/val.txt
# Precompute RAFT flow (256x448) for each dataset:
.venv/bin/python src/precompute_flow.py --frames-root data/DAVIS/JPEGImages/480p --out data/DAVIS/Flow --height 256 --width 448
.venv/bin/python src/precompute_flow.py --frames-root data/SegTrackv2/JPEGImages   --out data/SegTrackv2/Flow --height 256 --width 448
.venv/bin/python src/precompute_flow.py --frames-root data/FBMS/Testset            --out data/FBMS/Flow --height 256 --width 448
```

## 2. Train the three main variants (RQ1) + extra seeds
```bash
bash scripts/run_all_train.sh   # feed-forward -> energy critic (=amortized) -> baseline. ~3h. -> runs_video/
bash scripts/run_seeds.sh       # seeds 1,2 of the ff+energy path -> runs_video_s{1,2}/ (for error bars). ~1.7h
```
Individual pieces (what run_all_train.sh calls):
```bash
.venv/bin/python src/train_video.py  --variant feedforward --davis-root data/DAVIS --iters 8000 --lr 1e-3 --eval-every 500 --out runs_video --seed 0
.venv/bin/python src/train_energy.py --davis-root data/DAVIS --init-ckpt runs_video/feedforward.pt --iters 3000 --neg-steps 5 --lr 1e-3 --eval-every 500 --out runs_video --seed 0
.venv/bin/python src/train_video.py  --variant baseline --davis-root data/DAVIS --iters 5000 --lr 1e-3 --persistent --neg-steps 15 --step-size 5 --noise 0.02 --eval-every 500 --out runs_video --seed 0
```

## 3. Extension experiments (S4 modality, S5 capacity, flow baseline)
```bash
bash scripts/run_ext.sh                                   # S4 (runs_mod_rgb/flow) + S5 (runs_big, ch=64) -> results/ext_results.json. ~3h, resumable
.venv/bin/python src/flow_baseline.py --out results/flow_baseline.json   # trivial Otsu-on-|flow| (CPU, minutes)
```

## 4. Evaluate + generate all paper assets + compile
```bash
# Fair sampler tuning + RQ2 frontier + RQ3 transfer + figures/tables + PDF (one command):
bash scripts/run_eval_direct.sh          # needs results/sampler_tuning.json (below) OR run_rq2.sh does the tuning
# If sampler_tuning.json is missing, produce it first:
.venv/bin/python src/tune_sampler.py --ckpt runs_video/baseline.pt --root data/DAVIS --n 100 --val-n 128 --seed 0 --out results/sampler_tuning.json
# Across-seed error bars, dataset stats, extension tables/figures:
.venv/bin/python src/seed_agg.py         # -> results/seed_agg.json
.venv/bin/python src/dataset_stats.py    # -> paper/tables/datasets.tex
.venv/bin/python src/gen_tables_video.py # -> rq1_main.tex, rq3_transfer.tex, headline.tex
.venv/bin/python src/plots_video.py      # -> frontier_davis.png, train_efficiency.png
.venv/bin/python src/qualitative.py      # -> qualitative.png
.venv/bin/python src/gen_ext_tables.py   # -> modality.tex, capacity.tex, flow_transfer.tex, ext_headline.tex
.venv/bin/python src/plots_ext.py        # -> transfer_bars.png, capacity_frontier.png
# Compile:
cd paper && tectonic main.tex   # -> paper/main.pdf (15pp)
```

## 5. Regenerate only the paper (after editing prose, no re-run)
```bash
.venv/bin/python src/gen_tables_video.py && .venv/bin/python src/gen_ext_tables.py \
  && .venv/bin/python src/plots_video.py && .venv/bin/python src/plots_ext.py \
  && .venv/bin/python src/dataset_stats.py
cd paper && tectonic main.tex
```

## Gotchas (learned the hard way)
- Launch long jobs so they survive: use a background task runner, NOT `nohup cmd &` (gets reaped).
- Do NOT pipe training through `| tee` under `set -e` — it masks a crashed trainer's exit code.
- LaTeX macro names cannot contain digits (`\NumFkzero`, not `\NumFk0`).
- `read VAR < file` under `set -e` needs a trailing newline in the file.
- GPU may be shared by other sessions; jobs can be SIGKILLed — `run_ext.sh` is resumable
  (skips existing checkpoints).
